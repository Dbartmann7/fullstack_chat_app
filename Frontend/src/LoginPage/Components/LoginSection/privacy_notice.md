# How your data is stored

This application is a portfolio project intended for
demonstration purposes only. It is not intended for public use

***Do not use real usernames or passwords, and do not include any personal or sensitive information in chats.***

- Passwords are hashed with bcrypt before being stored, but usernames and messages are stored in plaintext.

- Account and chat data is not shared, and is only stored for the purposes of allowing this applicaiton to function.  

- Accounts are automatically deleted [x time] after creation, along with any chats or messages associated with the account.  

- Application data is hosted by Railway
